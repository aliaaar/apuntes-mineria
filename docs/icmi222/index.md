# ICMI222 · Evaluación de yacimientos

Geoestadística aplicada a la estimación de recursos: desde el análisis exploratorio de datos
hasta el modelo de bloques estimado.

**Software:** Maptek Vulcan 2026.1 · **Dataset de laboratorio:** proyecto demo `ICMI222`
(10.478 compósitos de ~5,2 m, Au y Cu, cuatro dominios R101, R102, R111 y R112).
